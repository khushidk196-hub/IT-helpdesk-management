# Approved Assumptions

- This related SLA feature uses the same 24/7 priority targets, 75% warning threshold, first-response definition, reopening behavior, and notification recipients as `sla-monitoring-notifications/assumptions.md`.
- SLA rules are editable by Admins only; Managers can view all SLA data and Agents can view accessible tickets' SLA state. Delivery is in-app only.
- Rationale: the catalog contains overlapping SLA feature bundles; one shared policy prevents mismatched calculations and notification behavior.
